# Ontola Homebrew tap

```sh
brew install --cask ontola/tap/spaceman
```

| Cask | App |
| --- | --- |
| `spaceman` | [SpaceMan](https://ontola.github.io/spaceman/): fast, open-source disk space analyzer and cleaner |

To update a cask to a new release, set `version` and `sha256`
(`shasum -a 256 SpaceMan-macOS.dmg`) in `Casks/<name>.rb`.
